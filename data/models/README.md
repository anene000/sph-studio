# モデルデータ（.obj）

サイズの大きい `.obj` は Git 管理から除外しています（`.gitignore` 参照）。
リポジトリには軽量サンプル `bunny_sparse.obj` のみ同梱しています。

## 追加のモデルを使う場合

1. 使用する `.obj` をこのディレクトリに配置する。
2. シーン JSON の `RigidBodies[].geometryFile` にパスを指定する（例: `data/models/xxx.obj`）。
3. 解析空間よりオブジェクトが大きい場合、ソルバ／API が **推奨倍率**を提示するので `scale` を調整する。

> GUI 経由では「② オブジェクトデータ呼び出し」でアップロードすると自動的にここへ登録されます。
