## 2. 既知の制約・今後の改善提案

### 2.1 周期境界の次元前提
- 現状の近傍探索・格子平坦化は 3D 前提（`grid_num[0..2]`）。2D シーンは既存同様に近傍探索が 3D 構造に依存する。
- **提案**: 近傍探索を次元一般化（`flatten_grid_index` の次元対応）し、2D 周期にも対応。

### 2.2 周期軸の格子数下限
- 周期軸は格子 3 セル以上が必要（stencil 重複回避）。小さすぎる領域は起動時にエラー終了する。
- **提案**: GUI 側で領域サイズ/粒子半径から周期可否を事前判定し、設定画面で警告表示（現状はジョブ起動後にソルバが検出）。

### 2.3 流入速度制御の物理的厳密性
- 流入ゾーンでの速度緩和は簡便で安定だが、圧力場との整合（流入面での密度・圧力の一貫性）は近似的。
- **提案**: 開放境界の本格対応として、流入バッファでの粒子生成／流出での削除（可変粒子数）や、Lastiwka/Adami 型の characteristic-based open boundary の導入を検討（要: counting sort/固定配列の可変長化）。

### 2.4 駆動力と目標流速の関係
- 完全発達流の平均流速は駆動力・粘性・チャネル幅に依存し、ユーザーは駆動力を直接指定する（平均流速の直接指定ではない）。
- **提案**: 目標平均流速を指定すると駆動力を自動調整する PI 制御オプション（`targetMeanVelocity`）を追加。

### 2.5 プロファイルの一般性
- parabolic プロファイルは単一横断軸の放物線に限定。矩形ダクトの 2 方向プロファイルや任意プロファイルは未対応。
- **提案**: プロファイル関数のプリセット拡充（plug/parabolic/power-law）と、2 横断軸対応。

### 2.6 UI/UX
- 数値入力は素の number 入力。範囲（例: `inletRelaxation`∈[0,1]）のスライダ化や、周期＋駆動力の「周期チャネル流プリセット」ワンクリック適用があると導入が容易。
- **提案**: プリセット（周期チャネル流／流入チャネル流）ボタンをサンプルシーンと連動。3D プレビューに周期軸・流入面の可視化を追加。

### 2.7 テスト
- ソルバの物理検証は有限性・再循環・流入追従の smoke 中心。
- **提案**: ポアズイユ流の解析解（放物線速度分布）との定量比較を自動テスト化し、回帰検知に組み込む。

## 3. 優先度付きロードマップ（提案）

| 優先 | 項目 | 概要 |
|------|------|------|
| 高 | 2.2 GUI 事前判定 | 周期可否・格子数の事前警告（実行前に気づける） |
| 高 | 2.7 定量回帰テスト | ポアズイユ解析解比較で物理正当性を継続担保 |
| 中 | 2.4 目標流速制御 | `targetMeanVelocity` の自動駆動力調整 |
| 中 | 2.6 プリセット/可視化 | 導入容易化・誤設定低減 |
| 低 | 2.3 本格 open boundary | 可変粒子数の流入出（規模大） |
| 低 | 2.1 次元一般化 | 2D 周期対応 |

## 4. まとめ

要件は満たしつつ、実運用での使いやすさ（事前検証・プリセット・可視化）と物理的厳密性（定量検証・本格 open boundary）に改善余地がある。まずは「実行前の妥当性提示」と「解析解による回帰テスト」を優先することで、誤設定の低減と品質の継続担保を図る。
