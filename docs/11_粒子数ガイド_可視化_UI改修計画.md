# 粒子数ガイド・結果可視化・ウィンドウ/UI 改修計画

- 作成日: 2026-07-30
- 契機: `particleRadius=0.002` で流体 ~508k 粒子 → Vulkan デバイスロスト（`vkQueueSubmit failed`）＋
  Visual C++ Runtime Assertion（GPU メモリ/計算破綻）。

---

## 改修項目と影響範囲

### ① 実行前の粒子数・実行可否の静的評価とガイド（最重要）
- **狙い**: 実行せずに、現在の設定から総粒子数・格子数を推定し、環境に対する実行可否を色分け提示。
  超過時は目標粒子数に収まる推奨 `particleRadius` を提案。
- **算定**（静的・メッシュ不要）:
  - 流体: ブロックごと `Π floor((end_i-start_i)·scale_i / (2·particleRadius))` の総和（支配項）。
  - 格子: `Π ceil(domainSize_i / (4·particleRadius))`（メモリ指標）。
  - 剛体は voxel 化依存のため近似注記（通常は流体が支配的）。
- **しきい値（目安）**: ~120k 以下=快適 / ~300k 以下=重い（GPU 推奨・時間大）/ 300k 超=危険
  （GPU デバイスロストの恐れ。粒子を減らすか CPU 実行）。推奨半径 `r·(total/目標)^(1/3)`。
- **影響**: フロントのみ（`lib/estimate.ts` 追加、S2 パラメータに即時表示、S4 実行に警告）。
  バックエンド/ソルバ変更なし。低リスク。

### ② 結果可視化に解析空間グリッドを常時固定表示
- **狙い**: 結果 3D で解析空間の枠/グリッドを常に固定表示し、カメラも解析空間基準で固定
  （フレームごとに点群でカメラが動くのを解消）。
- **影響**: バックエンドに `GET /api/jobs/{id}/scene`（出力の scene.json 返却）を追加 → **サイドカー再ビルド**。
  フロント `ResultViewer3D` に domain 枠+グリッド、`results` ページで scene 取得。中リスク。

### ③ ウィンドウがタスクバーにオーバーラップ／ボタン視認性
- **狙い**: ウィンドウを作業領域（タスクバー除く）に収める。
- **影響**: `tauri.conf.json` の window 設定（起動時 `maximized: true`＝Windows 作業領域にフィット、
  `center: true`、最小サイズ調整）。**Tauri exe 再ビルド**。低リスク。

### ④ フィット検証ボタンの意味を説明（キャプション）
- **狙い**: 「解析空間フィット検証」の役割をツールチップ＋補足文で明示。
- **影響**: フロント S1 のみ。極小リスク。

## テスト・ビルド検証
- 単体: `estimate` の値検証（例: r=0.002 で ~50万、r=0.02 で ~500）。backend pytest 継続緑。
- 結合: Chrome 本番バンドルで S2 の推定表示、S4 警告、結果の固定グリッド、S1 キャプションを確認。
- 同梱: サイドカー＋Tauri 再ビルド → 起動・新規計算・粒子数ガイド・結果グリッド・ウィンドウ収まりを実機確認。
- CI: `ci.yml` 緑維持。
