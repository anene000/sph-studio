# 機能一覧（詳細・受入基準つき）

- 作成日: 2026-07-30
- 対象: SPH シミュレータ GUI アプリケーション

凡例: 優先度 P0=必須(MVP) / P1=重要 / P2=拡張

---

## ① 設定ファイル（JSON）インポート／エクスポート

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F1-1 | JSON インポート | ファイル選択（Tauri ダイアログ）で `scene.json` を読込。スキーマ検証し各設定画面へ反映 | P0 |
| F1-2 | JSON エクスポート | 現在の GUI 設定を JSON 化して任意パスへ保存 | P0 |
| F1-3 | 自動生成 | ②〜⑥の実行時、`outputDir` に `scene.json` を自動生成（操作例の要件） | P0 |
| F1-4 | 検証エラー表示 | 不正キー・型・値域（例: `domainEnd>domainStart`）を画面上に明示 | P0 |
| F1-5 | 差分/上書き確認 | 既存ファイルへの上書き時に確認 | P1 |

**受入基準:** 手書き JSON を F1-1 で読み込み→編集→F1-2 で保存し、内容が往復で一致する。

---

## ② オブジェクトデータ呼び出し（.obj）

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F2-1 | OBJ 取り込み | `.obj` を選択/アップロードし `data/models` へ登録 | P0 |
| F2-2 | メッシュ情報表示 | 頂点数・外接ボックス（extent）・実寸を表示 | P0 |
| F2-3 | 3D プレビュー | react-three-fiber でメッシュを解析空間内に表示 | P0 |
| F2-4 | 複数オブジェクト | 複数 RigidBody / Block の追加・削除・複製 | P1 |
| F2-5 | 数値誤差対策連携 | 取り込み時にメッシュクリーニング状況（重複頂点/退化面）を表示 | P1 |

**受入基準:** 任意の `.obj` を取り込み、bbox と 3D プレビューが正しく表示される。

---

## ③ オブジェクト・解析空間 GUI 設定画面

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F3-1 | 解析空間設定 | `domainStart` / `domainEnd` を数値入力＋3D 枠プレビュー | P0 |
| F3-2 | オブジェクト配置 | `translation`（重心基準）・`rotation`・`scale`（倍率）を編集、プレビュー即時反映 | P0 |
| F3-3 | フィット検証 | `/api/config/validate` で解析空間超過を判定し、**推奨倍率**（アスペクト比保持/軸別）を提示 | P0 |
| F3-4 | 流体/剛体ブロック | `FluidBlocks` / `RigidBlocks` の start/end/velocity/color 等を編集 | P1 |
| F3-5 | 単位/軸ガイド | グリッド・軸・寸法ラベル表示 | P2 |

**受入基準:** 解析空間より大きい OBJ を配置すると、GUI 上に推奨倍率が表示され、適用でプレビューが空間内に収まる。

## ④ 計算パラメータ設定画面

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F4-1 | ソルバ選択 | WCSPH(0) / DFSPH(4) の切替 | P0 |
| F4-2 | 基本パラメータ | `particleRadius` / `timeStepSize` / `gravitation` / `density0` | P0 |
| F4-3 | WCSPH 係数 | `stiffness` / `exponent` | P0 |
| F4-4 | 計算範囲 | `totalTime` または `totalSteps`、`enforceDomainFit` | P0 |
| F4-5 | プリセット | パラメータの保存/呼び出し | P2 |
| F4-6 | 妥当性チェック | CFL 等の目安警告（timeStep が大きすぎる等） | P1 |

**受入基準:** 各パラメータが JSON の対応キーへ 1:1 で反映される。

## ⑤ 実行・ソルバ呼び出し（本プログラム主体）

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F5-1 | ジョブ作成 | 設定を集約→`scene.json` 自動生成→ソルバをサブプロセス起動 | P0 |
| F5-2 | ヘッドレス実行 | `run_headless.py` で描画非依存に計算（Vulkan/CPU） | P0 |
| F5-3 | 出力設定 | 追跡対象（流体のみ/オブジェクト別個）・列・**時間刻み間隔**を指定 | P0 |
| F5-4 | キャンセル | 実行中ジョブの中断（プロセス終了） | P0 |
| F5-5 | 事前検証 | 起動前に domain フィット/依存チェック、失敗時は推奨倍率提示で中止 | P0 |
| F5-6 | 逐次キュー | 複数ジョブの順次実行 | P2 |

**受入基準:** 実行すると `scene.json` が生成され、計算が進行し、指定間隔で CSV が出力される。キャンセルで即停止する。

## ⑥ 進捗画面

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| F6-1 | 進捗バー | step / totalSteps、simTime / totalTime、経過・ETA | P0 |
| F6-2 | ライブログ | ソルバ標準出力（JSONL/テキスト）を逐次表示 | P0 |
| F6-3 | 指標表示 | 粒子数・fps・現フレーム番号 | P1 |
| F6-4 | エラー表示 | 失敗時のメッセージ（推奨倍率含む）を明示 | P0 |
| F6-5 | 途中プレビュー | 直近フレームの簡易 3D 表示 | P2 |

**受入基準:** WebSocket 経由で進捗がリアルタイム更新され、完了/失敗/中断が状態表示される。

## 結果画面（操作例: 計算終了後のデータ取得）

| ID | 機能 | 詳細 | 優先度 |
|----|------|------|:---:|
| FR-1 | 3D 再生 | フレームスクラバでパーティクル/オブジェクトを再生（react-three-fiber） | P0 |
| FR-2 | CSV ダウンロード | 流体 CSV・オブジェクト CSV を個別/一括(zip)取得 | P0 |
| FR-3 | 追跡分離 | 流体のみ・オブジェクト別個の CSV を明確に分けて提示 | P0 |
| FR-4 | フレーム表 | frames.json（frame↔simTime↔ファイル）表示 | P1 |
| FR-5 | 簡易グラフ | 粒子数/密度等の時系列プロット | P2 |

**受入基準:** 出力 CSV が「流体のみ」「オブジェクト別個」に分かれて生成され、3D 再生とダウンロードができる。
